## 2. 這些問題怎麼疊在一起(一檔股票被主力倒貨時,系統看到什麼)

1. 主力開始賣 → 股票掉出主力買超榜(掉榜股有當天分點者 81% 為主力淨賣)。**G2**:引擎的賣方證據建立在一個「在榜時依構造為正」的數字上,賣壓只存在於榜外。
2. 主力賣得夠多 → 掉出主力買超榜。**G3**:缺席是透明的,連買天數不中斷;**G7**:沒有轉弱計算。
3. **G4**:黃金名單照樣列它,常常還是 PRIME。
4. **G6**:回測裡的持倉凍結,停損看不到這段跌幅。
5. 過幾天它又回到主力榜(短暫買盤)→ **G1**:那天亮「主力消失/轉弱」→ 策略**在買盤回來的那天出場**。

→ 設計上的「賣方證據」幾乎全部失效,系統只剩「有沒有上榜」一個訊號;而上榜本身(§0 基準)這段期間沒有預測力。
