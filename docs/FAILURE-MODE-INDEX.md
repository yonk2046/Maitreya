# 失效模式索引（Failure Mode Index）— 架構導案

> **狀態**：導案（proposal），**尚未核准落地**。2026-07-28 起草。
> **地位**：憲法（ARCHITECTURE_BLUEPRINT）之下。與 FORWARD-RISK-REGISTER 互補——
> 登記簿寫「**還沒發生**、預判會發生」，本檔寫「**已經發生過**、必須不再發生」。
> **紅線**：本檔不新增規範、不改判斷參數。它只做一件事——把已發生的事故按「軸」歸位，
> 並為每一列指名一個**可執行的守門員**。沒有守門員的列＝已知破口＝工作佇列。

---

## 0. 這份文件要解決的具體抱怨

> 「我常常叫你改一些東西，你改一改改一改，**隔天**的 pipeline 就會故障，已經遇過好多次了。」

關鍵字是**隔天**。不是當場壞——當場我會看到。是我驗完、綠燈、commit、收工，然後隔天早上壞。

---

## 1. 診斷：為什麼總是「隔天」

現有的兩道驗證面：

| 驗證 | 涵蓋 | 固定在 |
|---|---|---|
| `make test` | 邏輯正確性 | **執行的那一刻** × 凍結語料 |
| `verify_all_replay` | 歷史決定性 | **執行的那一刻** × 已歸檔的過去 |

兩者都是**單一時刻**的快照。但 pipeline 實際活在一個四軸狀態空間裡：

- **T 時刻**——盤前 08:35 / 盤中 09:00–14:00 / 盤後 19:00 / GHA 20:00 / cron 漂移後的任意時刻
- **D 日型**——交易日 / 週末 / 國定假 / 颱風假 / 連假後第一天
- **M 執行者**——Mac launchd（開機才有）/ GHA / cron-job.org / 兩者同時（race）
- **U 上游**——T86 晚發布 / CDN 對機房 IP 封鎖同日資料 / 來源回空 → 退回 cache

`make test` 跑在星期二上午十一點，它**結構上不可能**變動 T、D、M、U 任何一軸。
於是這四軸構成的整個象限是測不到的——而那正是事故住的地方。

**所以「隔天壞掉」不是改動本身有錯，是驗證面有一個固定形狀的洞。**
我在洞外面驗到綠燈，pipeline 在洞裡面跑。

## 3. 現有制度為什麼擋不住

你已經有的層，各自在做的事：

| 層 | 檔 | 職責 | 對「隔天壞」有效嗎 |
|---|---|---|---|
| 憲法 | `docs/ARCHITECTURE_BLUEPRINT.md` | C1–C12 規範正本 | 規範對，但不會自己執行 |
| 前瞻 | `docs/FORWARD-RISK-REGISTER.md` | 預判未來 3–12 月 | **有效但只涵蓋預判到的** |
| 薄規則 | `.claude/rules/*.md` | 情境自動載入 | **有效**——這是你的全域同步層 |
| 鉤子 | `.claude/hooks/protect-canonical.sh` | 擋改正典 | 有效但只有一顆 |
| 教訓 | `~/.agents/institution/lessons.md` | 跨平台通用教訓 | **只有 5 條，而且只能靠讀** |

問題出在最後一列。`lessons.md` 是**要人記得去讀**才生效的東西。
讀了就防住、忘了就再踩一次——它不是防線，是筆記。

**一條要靠記憶生效的教訓，不是預防。一條會讓 build 變紅的教訓，才是。**

## 4. 索引設計：小北百貨的走道編號

主索引不放內容，只放走道號。每一列長這樣：

```
| ID | 失效模式 | 軸 | 症狀（你會先看到什麼） | 根因 | 守門員（可執行） | 案例 |
```

設計上只有一條規矩，但它是全部的重點：

> **「守門員」欄必須指名一個真的會跑、會紅的東西**——一顆測試、一個 hook、一個 CI step。
> 填不出來的列，就誠實留白。**留白的列＝已知破口，那一欄就是工作佇列。**

這一條讓索引不會退化成又一份沒人讀的文件：它的每一列要嘛是活的防線，要嘛是待辦。
不存在「寫了但沒用」的中間態。

示範（前三列是本週剛落地的，守門員都是真的）：

| ID | 失效模式 | 軸 | 症狀 | 根因 | 守門員 | 案例 |
|---|---|---|---|---|---|---|
| F-1 | 降級抓取覆寫 latest pointer | T·D·U | 看板「現在大盤」變成隔夜值 | 抓取失敗仍無條件寫檔 | `tests/test_market_pulse.py` | 7/25 |
| F-2 | 執行日冒充資料日 | T·M | 昨日分點頂著今天的戳過鮮度閘門 | `date.today()` ≠ session date | `tests/test_branch_session_date.py` | 7/28 |
| F-3 | monkeypatch 視窗內 lazy import | S | 「加了 print 就變綠」 | from-import binding 綁到 patch 值 | `tests/test_replay_as_was_params.py` | 7/24 |
| F-4 | cron 漂移進盤中 | T·M | 幽靈 commit／盤中快照 | GHA cron 慣性延遲 3–4h | *(待補)* | 多次 |
| F-5 | 缺席被當證據 | D·U | 假日建出殭屍快照 | T86 缺席≠放假 | `_trading_day_oracle` fail-closed | 7/10 |
| F-6 | 判斷參數未走修正案 | P | 隔日回測數字無聲改變 | 變更未獨立成案＋verify | *(待補：pre-push 檢查)* | 7/16–17 |
| F-7 | 主觸發靜默死亡 | M | 表面正常，實際降級 | PAT 到期無人通知 | *(待補：heartbeat)* | R2 預判 |

四列有守門員，三列留白——**那三列就是接下來要做的事，不必再開會決定**。

## 5. 對應你聽到的「神龍引擎」四步

| 神龍四步 | 你這裡的現況 | 缺口 |
|---|---|---|
| ① 錯誤捕捉 | `lessons.md`（5 條） | 捕捉率偏低：七件事故只留下 ~3 條 |
| ② 尋找盲點 | **完全沒有** | ← **這就是本導案要補的那一格** |
| ③ 建立最高原則 | 憲法 C1–C12＋修正案流程 | 有，但教訓流不進去 |
| ④ 全域同步 | `.claude/rules/*.md` 自動載入＋hooks | 有，機制健全 |

**你缺的不是①③④，是②。** ①在記事、③④在執行，中間沒有人把散落的事故**歸軸**，
所以「每次都是同一類問題」這件事沒有任何地方會浮現出來。
第 2 節那張表就是②的產物——一做出來，「五件事都在時間軸上」立刻自己跳出來。

### 一個我不同意講座的地方

講座說 AI 發現規律後「**自動去修改自己的底層架構**」，全自動 90%。
**在這個 repo 我建議不要。** 你的憲法管的是判斷參數——一次錯誤的自動改寫會無聲汙染回測，
而且因為 replay 是決定性的，錯誤會被固化進歷史。你既有的「判斷參數＝修正案級＋需核准」
紀律是對的，不該為了自動化拆掉。

**建議的自動化界線：①→② 全自動，②→③ 停下來給你核准。**
機器負責「發現又是同一類」，人負責「所以要立什麼法」。

## 6. 最小落地（如果核准）

刻意做到最小——你上次已裁示制度提案走最小增量、不建平行文件：

1. **本檔**（1 個新檔）——就是第 4 節那張表，隨事故增列。
2. **1 行**——在 `.claude/rules/pipeline-tools.md` 加一行指向本檔，讓它在改 pipeline 時自動載入（櫃檯指路）。
3. **1 顆測試** `tests/test_clock_matrix.py`——凍結 (T, D) 去斷言會看時鐘的判斷點：

   已知會讀時鐘／日曆的判斷點共七個：
   `intraday_guard`、`_trading_day_oracle`、`_trading_day_gate`、`derive_trading_date`、
   `fetched_date`、`_pulse_is_fresh`、remote-first gate。

   矩陣格子（每格＝一顆參數化測試）：

   | 格 | 斷言 |
   |---|---|
   | 週六 11:52 | pointer 不得被覆寫 |
   | 交易日 08:35 盤前 | branch 戳記＝前一 session |
   | 交易日 11:00 盤中 | intraday guard 必須 abort |
   | 颱風假 | oracle fail-closed，不得建快照 |
   | Mac 關機（無 19:00） | 早班必須能補建昨日快照 |

   **這一顆測試就覆蓋第 2 節七件事故裡的五件。** 投入一個檔，關掉整個象限。

不做的事：不新增規範層、不動憲法、不改判斷參數、不建平行文件樹。

## 7. 維護規矩

- 每次事故**修完的同一個 commit**裡增列一行（趁上下文還在，不另開任務）。
- 新列若填不出守門員，**照樣寫入並留白**——留白才會被看見。
- 同一「軸」累積到 3 列，就是訊號：該往憲法提修正案，不是再補第 4 顆測試。
- 本檔只增不改；已修好的列保留（它是守門員存在的理由，刪掉下一個人就會拆掉測試）。
